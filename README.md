## 📌 Project Overview

**MarketLens** is an Exploratory Data Analysis (EDA) project that focuses on analyzing retail sales data to uncover meaningful patterns, customer behaviour trends, and business insights.

The project uses Python-based data analysis and visualization techniques to understand sales performance, customer demographics, product trends, and revenue patterns. The objective is to transform raw retail data into actionable insights that support data-driven business decisions.

---

# 🎯 Project Objectives

- Perform complete Exploratory Data Analysis on retail sales data.
- Analyze sales trends over time.
- Understand customer demographics and purchasing behaviour.
- Identify top-performing products and categories.
- Find relationships between numerical variables.
- Generate business recommendations from data insights.

# 📊 Dataset Description

The project uses a retail sales dataset containing transaction-level information.

Dataset features include:

- Customer details
- Product information
- Sales amount
- Quantity purchased
- Product categories
- Transaction dates

The dataset is analyzed to understand customer behaviour and business performance.

---

# 🔍 Exploratory Data Analysis Performed

## 1. Data Inspection

Performed initial analysis:

- Dataset shape
- Column information
- Data types
- Missing value detection
- Duplicate record checking

---

## 2. Descriptive Statistics

Calculated statistical measures:

- Mean
- Median
- Mode
- Standard Deviation

to understand numerical data distribution.

---

## 3. Time Series Analysis

Analyzed:

- Monthly sales trends
- Quarterly sales performance

### Insight:
Sales patterns help identify seasonal trends and changing customer purchasing behaviour.

---

## 4. Customer Demographic Analysis

Analyzed customer distribution based on:

- Age groups
- Gender categories

### Insight:
Customer demographics help businesses create targeted marketing strategies.

---

## 5. Product Analysis

Performed:

- Top 10 best-selling product analysis
- Category-wise revenue analysis

### Insight:
Identified products and categories contributing significantly to overall revenue.

---

## 6. Correlation Analysis

Created a correlation heatmap to understand relationships between numerical variables.

### Insight:
Correlation analysis helps identify important factors affecting sales performance.
